# estudos-SQL

## Objetivo
Este repositório foi criado para reunir projetos de estudo em SQL, utilizando
diferentes bases de dados fictícias com o objetivo de praticar consultas,
modelagem e análise de dados.

## Tecnologias utilizadas
- SQL
- Ambiente online (MyCompiler)

## Estrutura do repositório
Os projetos estão organizados em pastas, cada uma representando uma base de dados
ou contexto de estudo específico:

- /academia → Projeto de estudo com base de dados de uma academia


## Observações
Este é um repositório de estudos, voltado à prática e ao desenvolvimento contínuo
em SQL.
